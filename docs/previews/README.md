# Lesson slide previews

`electricity-slide-comparison.html` is a deterministic 16:9 visual regression fixture.

- `#before` shows the old generic keyword-map pattern.
- `#after` shows the semantic circuit layout introduced by LessonSlidePlan v3.

Open the file in a browser and switch between the two hash URLs to compare the slides. The preview is intentionally independent of AI and the remote LaTeX compiler so design regressions can be reviewed locally.
